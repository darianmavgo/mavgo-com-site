Mavgo is owned and operated by **Darian Hickman**. Mavgo serves as the home base of all software endeavors of Darian Hickman.

**Contact:** [darian@mavgo.com](mailto:darian@mavgo.com)

## Core Capabilities and Experience

Darian Hickman is a software engineer, entrepreneur, and builder focused on data systems, quantitative tools, and developer infrastructure. His work spans from low-latency Go data pipelines to cross-platform desktop apps, algorithmic trading engines, web games, and civic technology research.

## Project Highlight: Village Makeover

In 2013, Darian and several remote developers built Village Makeover — an isometric city-building web game — collaboratively across time zones. It was an early experiment in async remote software development.
